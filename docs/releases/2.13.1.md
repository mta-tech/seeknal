# 2.13.1 patch candidate

**Status: unreleased.** This patch is based on
[v2.13.0](https://github.com/mta-tech/seeknal/releases/tag/v2.13.0), released
on 2026-10-20. No 2.13.1 release date is assigned.

## Changes

- Bump `pyproject.toml`, `seeknal.__version__`, and the project entry in
  `uv.lock` from 2.13.0 to 2.13.1.
- Correct stale 2.13.0 candidate labels in release and upgrade documentation.

Runtime behavior and dependency versions are unchanged from 2.13.0.
The Prefect Dockerfile fix in [PR #112](https://github.com/mta-tech/seeknal/pull/112)
and dependency fixes in [PR #113](https://github.com/mta-tech/seeknal/pull/113)
remain unmerged and are not included in this patch.

## Upgrade considerations

No additional configuration migration is required from 2.13.0. Projects
upgrading from 2.12.1 should follow the [upgrade guide](../cli/upgrade.md).
The [2.13.0 verification and known limits](2.13.0.md#compatibility-and-verification)
remain applicable; this patch does not resolve the recorded macOS ARM native
crash or the Prefect image packaging issue tracked in PR #112.
